# ShopGuard Project Blueprint

## Tech Stack
- Backend: Python / Django
- Database: SQLite (shopguard.sqlite3)

## Core Apps
- `config`: Main project settings and routing
- `inventory`: App managing shop items, stock, or guards

## How to Run Locally
- Activate Virtual Environment: `venv\Scripts\activate`
- Run Server: `python manage.py runserver`
- Check Status: `python manage.py check`
